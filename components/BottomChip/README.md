A quiet footer chip for secondary switches such as language and theme.

## When to use
The onboarding footer (`AccountRegister`) and similar low-emphasis rows. Not for main actions — use Button.

## The consumer provides
`label`, `onPress`, and optionally `icon` (Lucide) and `accessibilityLabel`.

## Rules
- `caption` type in `fg-muted`, no fill or border; 44px minimum height for touch; press fades to 60%.

Hand-written web rendition of `cofferdam-app/src/components/ui/BottomChip.tsx`.
